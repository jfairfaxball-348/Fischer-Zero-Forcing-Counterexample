# Reference data

This directory contains only small source data needed to make the graph transcription auditable.

- `H24.g6` is the graph6 string printed in Mikko Fischer, arXiv:2607.23664v1, for the 24-vertex graph H = G(K3).

The repository does not redistribute the paper PDF. Consult the primary source directly for the construction, theorem statement, figure, witness descriptions, fort reduction, and bibliography.
